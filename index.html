what you get

One right-click. Full context.

tree-mapper/
├──

Full directory tree

A CLI-style hierarchy, directories before files, matching exactly what you see in the Explorer sidebar.

├──

Every file's source

60+ languages detected automatically and wrapped in fenced, syntax-tagged code blocks.

├──

Secrets redacted

API keys, tokens, private keys and passwords are caught locally and replaced with [REDACTED]. Files with a finding start unchecked and get a ⚠ badge.

├──

Respects .gitignore

Ignored files start unchecked and stay out of the tree. Parent and nested .gitignore files are honored, with ! negation.

├──

Interactive file picker

Check exactly which files go in. Search, filter, restore your last selection or save named presets — fast even with thousands of files.

├──

Select changed / staged

One click picks the files git status reports, so you can snapshot exactly what you're working on.

├──

Index & token count

Every snapshot opens with a linked jump-to-file index and an estimated token count, so you know how much context it'll use before pasting.

└──

Snapshot history

Keeps a rolling set of your last snapshots in .tree/, deleting the oldest automatically.

how it works

Three steps, no setup.

1

Right-click a folder

In the Explorer, choose Tree Mapper: Generate Snapshot — or run it on the workspace root from the Command Palette.

2

Choose your files

A picker opens with sensible defaults already checked. Uncheck anything you don't need, or restore your last selection.

3

Get your markdown

Saved to .tree/. The notification offers Show in Folder, Open File and Copy File — nothing touches your clipboard until you click.
